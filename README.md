# Pathfinding Studio

An interactive, high-performance web application designed to visualize, analyze, and benchmark graph traversal and pathfinding algorithms in real-time. Built with React, TypeScript, and Tailwind CSS.

---

## Key Features

- **Multiple Algorithms**: Implementation and visualization of Dijkstra's Algorithm, A* Search, Bidirectional A*, and Jump Point Search (JPS).
- **Algorithm Duel Mode**: Side-by-side comparative benchmarking pitting Dijkstra against A\* to evaluate execution speed, visited nodes, and path efficiency simultaneously.
- **Interactive Grid Editor**: Real-time manipulation tools for drawing impassable obstacles (walls) and high-cost terrain (weighted nodes/swamps).
- **State Persistence**: Local storage integration to save custom grid configurations and maps.
- **Responsive & Modern UI**: Engineered with a clean glassmorphism aesthetic, smooth frame-rate animations, and full accessibility support.

---

## Tech Stack

- **Core**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
